
<h3>WorldPainter is a powerful tool for creating custom terrains. With it, we can even make smooth snowy landscapes using Vanilla Minecraft’s snow layers. Conquest Reforged adds a plethora of layer blocks that emulate these snow layers and are perfect for terrains, but WorldPainter doesn’t support using these straight out of the box.<br/></h3><h4>Thankfully, with a bit of tweaking and a few steps, we can use Conquest Reforged layers in our terrains:</h4><p>1. Find the file called <em>worldpainter.vmoptions </em>located wherever you installed WorldPainter. For me, this was at <em>C:\Program Files\WorldPainter</em>. You’ll want to open this file.</p><figure style="max-width:938px" class="w-richtext-align-fullwidth w-richtext-figure-type-image"><div><img alt="" src="/assets/66f41c5c2cc1dcf39e76f5a8_66f41be0b3c25a66b287cb39_worldpainter_layer_guide_1.webp" loading="lazy"/></div></figure><p>‍</p><p>2. Copy and paste this line into <em>worldpainter.vmoptions</em>: -Dorg.pepsoft.worldpainter.smoothGroundCover=true</p><figure class="w-richtext-align-center w-richtext-figure-type-image"><div><img alt="" src="/assets/66f41c5c2cc1dcf39e76f595_66f41c0d929deba359219638_worldpainter_layer_guide_2.webp" loading="lazy"/></div></figure><p>‍<br/></p><p>3. Launch WorldPainter. Hit File -&gt; New World (ctrl+n) and select [Beta] Minecraft 1.15 for the map format. Make sure <em>Extended block IDs </em>is enabled as well. If you have an existing world, you can hit </p><figure class="w-richtext-align-center w-richtext-figure-type-image"><div><img alt="" src="/assets/66f41c5c2cc1dcf39e76f5b8_66f41c19302da2b4c79e0db8_worldpainter_layer_guide_3.webp" loading="lazy"/></div></figure><p>‍<br/></p><p>4. Make a custom ground cover layer. This will be what adds the Conquest Reforged layers.</p><figure class="w-richtext-align-center w-richtext-figure-type-image"><div><img alt="" src="/assets/66f41c5c2cc1dcf39e76f5b5_66f41c2b8c918dd1ef45d2ff_worldpainter_layer_guide_4.webp" loading="lazy"/></div></figure><p>‍<br/></p><p>5. Create a <em>new custom material</em>. For this example, we’ll use Conquest Reforged’s grass layer. Hit <em>Custom </em>and enter in <em>conquest </em>for the first box and <em>grass_block_layer</em> for the second. This is the block id. For other layers you can find the id by opening Minecraft’s debug screen (hit f3 while in-game) and hovering other the block in question. Next, add a property, call it <em>layers, </em>and select <em>Integer </em>(default is boolean). Change the default number from 0 to 8 (this is the final layer shape). </p><figure class="w-richtext-align-center w-richtext-figure-type-image"><div><img alt="" src="/assets/66f41c5c2cc1dcf39e76f5af_66f41c3a1996693ba7d94c9d_worldpainter_layer_guide_5.webp" loading="lazy"/></div></figure><p>‍<br/></p><figure class="w-richtext-align-center w-richtext-figure-type-image"><div><img alt="" src="/assets/66f41c5c2cc1dcf39e76f5ab_66f41c46f38383699b6d34a9_worldpainter_layer_guide_6.webp" loading="lazy"/></div></figure><p>6. Finish making your custom material and return to the custom ground layer window. Check off smooth. Then, press OK.</p><figure class="w-richtext-align-center w-richtext-figure-type-image"><div><img alt="" src="/assets/66f41c5c2cc1dcf39e76f5b2_66f41c4e0bbdddeb946eaf02_worldpainter_layer_guide_7.webp" loading="lazy"/></div></figure><p>7. You’re ready to start painting!</p><h5>Note: While it’s possible to add plants on top of these layers by using another smooth ground cover layer and setting the thickness to 2 (or more if you want them to be taller), my tests found that this ends up exporting odd banding patterns. As such, I won’t be going into detail regarding plants here. If anyone finds a reliable and non-glitchy way to add plants on top of layers painted through this method, let us know!</h5>
