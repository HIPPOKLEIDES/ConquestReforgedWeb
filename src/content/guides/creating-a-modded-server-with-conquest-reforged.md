
<p>Making a modded server for Minecraft can be a bit tricky, especially when the process changes across different Minecraft versions, guides become outdated, and instructions can be a bit too technical or vague. As such, I’ve put together this guide to make the process a little bit easier for those who are inexperienced with servers and want to start playing Conquest Reforged with a few friends. <br/></p><p>You’ll first want to decide whether you want to rent a server from a host or run a server off of your own computer. <br/></p><p>Also, please note that Minecraft Realms do not support mods.</p><h4><strong>SERVER HOSTS:</strong><br/></h4><p><strong>Renting a server can make the setup process much simpler, and it’ll also be online 24/7. You’ll probably want to go this route if your own machine/computer isn’t strong and doesn’t have RAM to spare.</strong> I&#x27;ve tested different server hosts geared towards Minecraft, and for us <a href="https://client.witherhosting.com/?affid=1589">Witherhosting </a>has worked best, as it offers fairly good performance for a reasonable price. In my experience, many server hosts charge a premium that ends up going to unnecessary features and loads of marketing.<br/></p><p><a href="https://client.witherhosting.com/?affid=1589">Witherhosting</a> offers many different plans, as will other hosts. Conquest Reforged on the server-side actually isn’t very demanding in terms of RAM, alth. This is largely because the server doesn’t have to load and cache all of the block models and textures; all of this is handled by the client (ie: your computer). Minecraft itself seems to be the culprit of higher RAM levels being necessary. Most of the server resources go towards actually running the world, the entities in it, and supporting all the players online.<strong> I&#x27;d recommend at the minimum a plan with 4gb. You’ll want to scale the amount of RAM up depending on how many people will be playing at the same time, how high you have certain settings turned up like render distance, and if you want to do large-scale WorldEdit operations.</strong></p><p><strong>After purchasing a server, you’ll need to install Conquest Reforged on it.</strong> You&#x27;ll only need the Conquest Reforged mod installed. The CR Recipes mod, and Conquest Medieval Weapons and Armors mod are optional.<br/><br/></p><h4><strong>RUNNING A SERVER ON YOUR MACHINE:</strong><br/></h4><p><strong>If you have RAM to spare, want to save some money, and don’t care about your server running 24/7, this is probably the route you’ll want to go.</strong> In any case, the steps taken for this process might be useful to know for those of you who want to explore more advanced server configurations or host larger servers, perhaps on a machine dedicated to running your Minecraft server. </p><h5><strong>For Minecraft 1.15.2:</strong><br/></h5><ol role="list"><li>First, create a folder for where you want to store your server’s files. This can be pretty much anywhere, just make sure that you have read/write privileges in the location and that it isn’t a space for temporary files that get deleted.</li><li><a href="https://files.minecraftforge.net/net/minecraftforge/forge/index_1.15.2.html">Download the Forge installer for 1.15.2</a>. The latest will do.</li><li>Run the Forge installer. You’ll need <a href="https://java.com/en/download/manual.jsp">Java</a> to be able to do this as well as your server. Choose the 64-bit version. Select “<em>Install server”</em> and enter the file path for the folder you made in step #1. </li></ol><figure class="w-richtext-align-center w-richtext-figure-type-image"><div><img alt="" src="/assets/66f41b24452c64e05a345b63_66f41b1b8cf6561310e8914d_server_guide_1.webp" loading="lazy"/></div></figure><p>‍<br/></p><ol role="list"><li> Navigate to your server’s folder. Run “<em>minecraft_server.1.15.2.jar”. </em>This will generate the “<em>eula.txt”</em> file. Open that and change “<em>eula=false”</em> to “<em>eula=true”</em>.</li><li>Run “<em>minecraft_server.1.15.2.jar” </em>again, this will generate additional files you’ll need to run and configure your server, such as a whitelist, ban list, world save, etc. A window called “Minecraft Server” should have opened. This is your server console. Close it for now.</li><li>Open <em>PowerShell </em>or <em>cmd </em>in your server’s folder (hold shift and right click the empty area of the folder). Run the command:<br/><br/><em>java -Xmx4G -jar forge-1.15.2-31.2.55.jar<br/><br/></em>Note: -Xmx4G means I’ve assigned 4gb of RAM to the server. Change this argument as you see fit. Also, Forge may update at some point, or you may have downloaded the recommended rather than the latest version. Simply replace <em>forge-1.15.2-31.2.55.jar </em>with whatever forge jar is in your server’s folder to get this working properly.</li><li>Your server is running! However, you properly don’t want to open PowerShell every time you want to play. You can make a <em>BAT file</em> (eg: <em>launchserver.bat)</em>, open it in a text editor, and paste in the command we used above. With that, just double click the bat file and your server should launch.</li><li>Install <a href="https://www.curseforge.com/minecraft/mc-mods/conquest-reforged?gameCategorySlug=mc-mods&amp;projectID=250077">Conquest Reforged</a> by dropping the mod jar from the link into your server folder’s mods folder. For all other mods you want to install, this is how you do it. Remember, client-side mods such as Optifine or the resourcepack <strong>should not</strong>be installed here!</li><li>Now you need to allow for other people to connect to your server while it’s running. The easiest method is to install <a href="https://www.vpn.net/">Hamachi</a>. A harder method (if you haven’t done it already for other games) is called Port Forwarding. Since this method varies according to your hardware and can carry some security risks, I won’t be going into this method.</li><li>With Hamachi installed and running, click the <em>Network </em>tab and make a new network. Make sure everything is online in Hamachi. You should see something resembling an ip address (eg: 26.73.1.114). This is what you and your friends will want to use to connect to your server.</li></ol><h5><strong>Common Issues:</strong><br/></h5><p>“I can’t use Conquest Reforged blocks on my server, but I can in singeplayer!”</p><ul role="list"><li>This means that your server isn’t running Conquest Reforged and you haven’t installed it properly.</li></ul><p>‍</p>
