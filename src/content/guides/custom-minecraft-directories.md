
<p>‍</p><p><br/></p><p>The Vanilla Minecraft Launcher offers the most stable, supportable, and surest way of successfully installing mods. However, this method can often confuse new players and hide the benefits for even experienced modders with unfamiliar terms. As a result, many modders are unaware that the Vanilla Minecraft Launcher allows one to seamlessly switch between different Minecraft versions without reorganizing their mod and resourcepack files while keeping separate configurations and settings for each version. All of this is accomplished easily with <em>custom Minecraft directories</em>.</p><p><br/></p><p>What is a directory? A directory is essentially a folder on your computer where important files are stored. In this case, a Minecraft directory stores all of the files you use and make while playing the game. These files include: saves, screenshots, mods, resourcepacks, shaderpacks, configs, settings, crash-reports, game logs, and game versions. The default Minecraft directory is called the <strong>.minecraft </strong>folder (often found at <em>C:\Users\&lt;your-computer-username&gt;\AppData\Roaming\.minecraft</em>). If you’ve ever used the official Conquest Reforged launcher, you can find its Minecraft directories nearby sitting in <strong>.conquestreforgedlauncher\instances</strong><em>.</em></p><p><br/></p><p>To make a custom Minecraft directory, we essentially need to follow the process for a <a href="/download-instructions#ManualInstructions">manual installation</a>, but with a few extra steps:</p><p><br/></p><ol role="list"><li><strong>Make a new, empty folder. This will be your new custom Minecraft directory.</strong> To keep things organized, we’ve made this folder in the same location as the default Minecraft directory. For further organization, we’ve also specified the version and which mod or modpack the directory will contain, naming it <strong>.minecraft1.15.2-CR</strong>. </li><li><strong>In the vanilla Minecraft launcher, click on the <em>Installations </em>tab and hit the <em>New Installation</em> button.</strong></li><li><strong>For <em>Version</em> pick the appropriate version of Forge that you’d like your custom Minecraft directory to run. </strong></li><li><strong>For <em>Game Directory, </em>copy and paste the file path of the folder you made in the first step. </strong></li><li><strong>Hit <em>Less Options.</em> Scroll down so that you can see <em>JVM Arguments. </em>Change -Xmx2G so that you have enough RAM to run Conquest Reforged. 6G is the minimum, 8G is recommended (ie: -Xmx8G). </strong></li><li><strong>Hit <em>Save</em>. Then hit <em>Play</em> so that the game can generate all the necessary files and folders in your new directory.</strong></li><li><strong>Install your mods, resourcepacks, and shaderpacks into your new directory as you would in a </strong><a href="/download-instructions#ManualInstructions"><strong>manual installation</strong></a><strong>.</strong></li></ol><p>‍</p>
