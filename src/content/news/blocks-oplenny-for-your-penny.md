<figure style="max-width:1277px" class="w-richtext-align-fullwidth w-richtext-figure-type-image"><div><img alt="" src="/assets/66f353e961a90f310ac2aaa9_66f353e5fc18e100da520581_1.15_patreon_article_img.webp" loading="lazy"/></div></figure><h3>Hey everyone,</h3><h4>We are releasing an alpha version of 1.15.2 Conquest Reforged to our patrons/donators as we await Forge-compatible Optifine for 1.15.2, whose release date is pretty uncertain. While connected textures won&#x27;t be available, there are loads of new blocks, models, and mechanics to check out and get an idea with what you&#x27;ll be able to achieve with the next iteration of Conquest Reforged. </h4><h4>In order to gain access to the alpha build, join our <a href="https://discord.gg/ZagrZvn">Discord</a> and <a href="https://donatebot.io/checkout/164052674637987840">donate here</a> for a special role that will give you the ability to download both Conquest Reforged and Terraforged.</h4><h4>Since this is an alpha and work-in-progress, we&#x27;re very open to feedback regarding what we can improve. With that, here is a rough changelog:</h4><h3>Conquest Reforged 1.15.2 Alpha Changelog</h3><h4>Blocks/Items/Models:</h4><ul role="list"><li>A full list will be compiled for the official release</li><li>The mod now has 11,827 blocks/models (subject to change)</li></ul><h4>	Block Variants:</h4><ul role="list"><li>Gothic Arches, Segmental Arches, Round Arches</li><li>Old half arch model removed (open to potential replacements for specific use cases)</li><li>Upside-down capitals/hopper shapes</li><li>Slabs now have “layers”. These layers can be placed upside-down</li><li>Corner Slab added</li><li>Eighth Slab added</li><li>Quarter Slab added</li><li>Two new shapes for the Sphere/Dragon Egg block</li><li>Vertical Corner blocks, Vertical Quarter blocks, and Vertical Slabs all have 3 “layer” shapes. Therefore, previous trapdoor and vertical slabs are merged</li><li>“Trapdoor” shape is now 8 pixels (32 pixels being a full-block) wide instead of 6 pixels, to be proportional with the other Vertical Slab layers.</li><li>Vertical Slab Corner (looks like a stair cut in half) added</li><li>Glass blocks now have Vertical Corners, Vertical Quarters, Vertical Slabs with working culling</li></ul><h4>	Mechanics:</h4><ul role="list"><li>Plants and rocks now “sink” into layers, so that they don’t appear as if they’re floating in mid-air when placed above them.</li><li>Pressing ‘B’ toggles between layers when placing snow/similar variants</li><li>Experimental variant toggle GUI when pressing “B” (can be enabled in the configs)</li><li>Most blocks can be waterlogged</li></ul><h4>	Interface/GUI:</h4><ul role="list"><li>Prompt to install Optifine/Resourcepack, if missing, on startup (can be disabled after first launch)</li><li>Notification that explains how to use the block picker GUI when the creative inventory is opened for the first time</li><li>Block picker GUI color palette functionality has been removed</li><li>Block picker settings have not been fully implemented yet. Some of the options can be found &amp; adjusted in the client config file (UI elements will be added later)</li><li>“Bite” food variants now appear in the block picker</li><li>Replaced vanilla GUI textures in the title screen and realms page with Conquest ones</li><li>Added Conquest GUI textures for new vanilla workstations</li><li>Reorganized Creative Tabs</li></ul><h4>	Survival:</h4><ul role="list"><li>Removed Conquest world generation (will be replaced with the TerraForged mod)</li><li>Breaking plants by hand no longer drops them as an item</li><li>Until new tree assets are created, saplings will no longer grow into trees</li><li>Removed all block/item recipes until new crafting mechanics are implemented</li></ul><h4>Bug/General Fixes:</h4><ul role="list"><li>Fixed Z-fighting on 3D models</li><li>Removed all unused blockstates (green “none” blocks)</li></ul><h3>‍</h3>
